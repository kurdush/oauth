# OAuth 2.0 Presentation

An interactive HTML presentation explaining OAuth 2.0 authentication protocol with real-world examples.

## 🚀 Live Demo

View the interactive presentation: [OAuth 2.0 Presentation](https://kurdush.github.io/oauth/)

## 📋 What's Covered

This presentation covers:

### OAuth Fundamentals
- **What is OAuth?** - Authorization protocol basics
- **Why OAuth?** - Security benefits and use cases
- **OAuth Actors** - Resource Owner, Client, Authorization Server, Resource Server

### OAuth 2.0 Flow
- **"Sign in with Google"** - Complete step-by-step walkthrough
- **6-Step Authorization Dance** - Detailed flow explanation
- **Access Tokens vs Refresh Tokens** - Token management

### OAuth 1.0 vs 2.0
- **Key Differences** - Complexity, security, implementation
- **Migration Path** - Why 2.0 won
- **Real-World Usage** - Which companies use each version

### Code Examples
- **OAuth 1.0 Implementation** - Complex signature generation
- **OAuth 2.0 Implementation** - Simple token usage
- **JavaScript/Node.js Examples** - Practical code samples

### Real-World Examples
- **Google OAuth** - Gmail, YouTube integrations
- **Discord OAuth** - Gaming applications
- **Spotify OAuth** - Music streaming apps

## 🎯 Key Takeaways

- OAuth 2.0 is the industry standard for API authorization
- Bearer tokens are much simpler than OAuth 1.0 signatures
- HTTPS is required for OAuth 2.0 security
- Popular services: Google, Facebook, GitHub, Microsoft, Discord, Spotify
